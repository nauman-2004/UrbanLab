# UrbanLab V2 — approved design references

- `1-workspace.png`, `2-interview.png`, `3-findings.png`: approved screenshots
- `mockup.html`: the static mockup they were taken from (open it directly; add `#interview` or `#report` to the URL)

The implementation in `frontend/` follows these, with two deliberate changes:
- Fictional building names in the synthetic demo data, so invented numbers aren't attributed to real towers.
- Headline numbers are computed from the data instead of hard-coded (e.g. 3.3× rather than the mockup's 3.4×).
